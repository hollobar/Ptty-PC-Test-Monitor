Ptty PC Test Monitor
=======================

PttyPcTestMonitor.exe 하나만 복사해서 실행하면 됨 (설치 없음, Windows 10/11 기본 .NET Framework 4.8 사용).
실행 시 관리자 권한(UAC) 확인이 뜸.

표시 항목 (현재 / 최소 / 평균 / 최대)
- CPU: 사용률, 온도, 전력, 클럭
- GPU: 사용률, 온도, 핫스팟, 전력, VRAM  — NVIDIA / AMD 모두 그래픽 드라이버만으로 동작
- RAM: 사용량, 사용률, 온도
  (RAM 온도는 DIMM 온도 센서가 있는 램만: 대부분 DDR5, DDR4는 거의 없음)
- FPS: 맨 앞에 있는 프로그램(게임/벤치)의 FPS, 1% Low, 프레임타임
  · 게임에 아무것도 주입하지 않는 방식(ETW, PresentMon과 같은 원리)이라 안티치트에 걸리지 않음
  · 대상 프로그램이 바뀌면 FPS 통계는 자동으로 새로 시작
  · 이 창을 클릭해도 대상은 바뀌지 않음 (직전 프로그램 유지)
- 네트워크: 다운로드 / 업로드 속도 (Mbps)
- 팬: 그래픽카드 팬, 메인보드 팬 헤더, USB 수냉(NZXT Kraken 등) 펌프/팬
  한 번이라도 돌아간 팬만 줄이 생김 (연결 안 된 헤더는 표시 안 함)
- 그래프: CPU·GPU·RAM 사용률, FPS

최소 / 평균 / 최대는 마지막 초기화 이후 기준. 창 위쪽 시간은 초기화 후 경과 시간.

보기 모드 (옵션 → 일반)
- 기본: 항목마다 패널. 배치 탭에서 패널을 자유롭게 배치.
- 간략히: 배치와 그래프는 그대로, 값 표시만 간단하게 바꿈.
    열 제목 없이 현재 값 옆에 ↓최소  ~평균  ↑최대 순으로 작게 표시 (단위는 현재 값에만).
    표시할 값은 기본 보기와 같이 선택 가능. 가로 한 줄로 보고 싶으면 배치에서 "가로 1줄"을 고르면 됨.
- 우클릭 메뉴에서 기본/간략히 보기와 투명도 슬라이더 표시를 바로 바꿀 수 있음.

CPU 온도 / RAM 온도 / 메인보드 팬
- PawnIO 드라이버가 필요함. 없으면 창에 노란 안내가 뜸 → 클릭하면 winget으로 설치.
- 설치 후 약 10초 안에 자동으로 표시됨 (안 되면 프로그램 재실행).
- 직접 설치: https://pawnio.eu  또는  winget install namazso.PawnIO
- 그래픽카드 팬, 수냉 펌프는 PawnIO 없이도 표시됨.

모니터 창 조작
- 왼쪽 드래그: 창 이동
- 창 가장자리 드래그: 크기 조절
    · 가로로 늘리면 글자·그래프가 같이 커짐
    · 세로로 늘리면 그래프 높이가 커짐 (간략히 보기는 가로만 조절)
- 상단 버튼: 초기화(↻) / 항상 위(핀, 파란색 = 켜짐) / 닫기(X)
- 우클릭: 보기 설정 (현재 모드 표시, 마우스를 올리면 기본/간략히 선택) / 투명도 슬라이더 표시 /
          옵션… / 배치 설정… / 종료

옵션 창 (모든 변경은 바로 적용·저장됨)
- 일반: 보기 모드, 항상 위, 투명도(슬라이더), 모니터 창 아래 투명도 슬라이더 표시, 갱신 주기,
        초기화 버튼 표시, 더블클릭으로 초기화(기본 꺼짐), 패널마다 열 제목 표시
- 표시 항목: 항목/줄별 표시·숨김(트리), 표시할 값(현재·최소·평균·최대), 그래프별 표시·숨김
    · 트리에서 줄(예: CPU의 온도)을 끌어서 같은 항목 안의 순서를 바꿀 수 있음
      (끄는 동안 마우스 옆에 끌고 있는 이름이 표시됨. 항목 이름 위에 놓으면 맨 위로)
    · 선택한 항목의 순서 초기화 / 전체 순서 초기화 (확인 창에서 "예"를 눌러야 초기화)
    · 바꾼 순서는 모니터 창(기본·간략히), CSV의 팬 열 순서에도 적용됨
- 배치: RTSS 오버레이 편집처럼 칸 위에 패널을 배치
    · 열 개수: 격자의 열 수 (1~6)
    · 빠른 배치: 세로 1열 / 2열 / 가로 1줄
    · 패널을 끌어서 이동, 오른쪽 아래 모서리(◢)를 끌어서 차지하는 칸 수(가로×세로) 조절
    · 겹치게 놓으면 자리를 바꿈
    · 열 전체나 행 전체가 비면 그 열·행은 자동으로 없어지고 뒤쪽 패널이 당겨짐 (편집 화면과 모니터 창 모양이 같음)
    · 일부 칸만 빈 경우는 그대로 둠
    · 여러 칸을 차지하는 패널은 넓어지고, 그래프가 있으면 그래프가 커짐
    · 숨긴 항목은 빗금으로 표시. 모니터 창에서는 빠지고 나머지 패널이 붙음
    · 칸을 더블클릭하면 그 항목의 편집 창이 열림 (모니터에 보이는 모습 그대로, 실시간)
        - 값 열(현재·최소·평균·최대)은 좌우로, 줄은 이름을 잡고 위아래로 끌어서 순서 변경
        - 지금 자리는 회색 점선, 옮겨질 자리는 파란 점선으로 표시
        - 값 열 순서는 항목마다 따로 저장됨 (CPU만 바꾸면 GPU는 기본 순서)
        - 창 크기를 바꾸면 패널도 커짐. 값 순서 초기화 / 줄 순서 초기화 (확인 창 있음)
- 기록·도구: 초기화, CSV 기록 시작·중지, 기록 폴더 열기, PawnIO 설치, 센서 목록 저장

설정은 %LOCALAPPDATA%\PttyPcTestMonitor\settings.ini 에 저장됨.

CSV 기록
- 문서\PttyPcTestMonitor 폴더에 저장 (기록 중엔 상단에 빨간 점)
- FPS 대상 프로그램 이름, FPS, 1% Low, 프레임타임, 네트워크 속도도 기록
- 팬 열은 기록을 시작한 시점에 감지된 팬 기준

벤치마크·게임과 같이 볼 때
- "전체 화면(독점)" 모드로 돌면 어떤 오버레이 창도 그 위에 보이지 않음.
  보조 모니터에 띄우거나, 창 모드/테두리 없는 창으로 실행할 것.
  못 보더라도 CSV 기록을 켜두면 테스트 후 전체 기록 확인 가능.
- FPS는 게임 화면을 클릭해 둔 상태(게임이 맨 앞)에서 측정됨.

색상 기준 (노랑 / 빨강)
- CPU 온도 80 / 90°C, GPU 온도 75 / 85°C, GPU 핫스팟 90 / 100°C, RAM 온도 60 / 75°C

문제 확인
- 값이 "—"로 나오면 옵션 → 기록·도구 → "센서 목록 저장" 결과 파일을 확인.
- 명령줄: PttyPcTestMonitor.exe --dump 결과.txt
- FPS 확인: PttyPcTestMonitor.exe --fps-test 결과.txt (10초간 프로그램별 present 수 기록)
- 화면 미리보기: PttyPcTestMonitor.exe --render 폴더 (예시 값으로 각 배치를 PNG로 저장)
